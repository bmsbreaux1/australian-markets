# australian-markets

The GOA Markets desk, ported to Australia's offshore basins.

- Open: https://claude.ai/artifact/6j2pebhTSHmV3xNatQNLFT

## What is on it

- **Producers:** the operators working offshore Australia
- **Market Brief:** a written read on the basin
- A link back to the Gulf of America desk

The header is an animated reef: bright blue water, surf, kites and a few great whites.

## Why I built it

To test whether the Gulf market desk was a one-off or a pattern. It is a pattern: the same layout took a new basin with new data.
